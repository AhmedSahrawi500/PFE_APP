# ESTL Grades — How to Run

## Requirements
- Node.js **v22+** (required for built-in SQLite)
- npm

## 1. Start the Backend
```bash
cd backend
npm install
npm start
```
Server runs on: http://localhost:5001

## 2. Start the Frontend (new terminal)
```bash
cd frontend
npm install
npm run dev
```
App opens at: http://localhost:5173
